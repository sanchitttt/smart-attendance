# Technology Interview Guides

These guides cover the basics of the main technologies used in Smart Attendance. Each is a separate read so you can focus on one subject at a time. The interview questions are about concepts and trade-offs, not memorizing this repository's code.

- [React basics and interview questions](react-basics.md)
- [React Native basics and interview questions](react-native-basics.md)
- [Spring Boot basics and interview questions](spring-boot-basics.md)
- [Next.js basics and interview questions](nextjs-basics.md)

## Suggested order

1. Read **React** first. React Native and Next.js both use React concepts.
2. Read **React Native** to learn how those concepts apply to mobile apps.
3. Read **Next.js** to learn how React is organized into a web application with server and browser rendering.
4. Read **Spring Boot** to understand the Java backend that the apps call.

For any interview answer, explain the concept simply, give a familiar example, and mention a trade-off or limitation when you can. You do not need to memorize the exact wording.
